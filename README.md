# nature-journaling-application
This is a personal project as part of my portfolio. Inspiration for this app came from my love of the environment and my passion for sustainability.

This application is currently in development.

Developed in Android Studio, Java.

This application serves as a personal journal, where the user can journal any nature they come across, whether on a walk or on holiday/out and about.

The user can create new entries, edit entries, view entries, delete entries and can personalise the app, search through their journals and entries are ordered by date.

I have additional ideas for other features I may implement, such as a bookmark feature. My settings will currently be limited - modifying appearance.

This app also serves as a method to improve the individual's mental health. The activity serves the purpose of being a relaxing hobby and for the user to slow down, observe their surroundings and indulge.
